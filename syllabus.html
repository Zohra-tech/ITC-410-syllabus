SYLLABUS

ITC 410

Web Development

This course introduces students to the principles and practices of web development using HTML, CSS, and bootstrap. Also concept of development and implementation of Database and also practice PHP.

Instructor: Nirmal Adhikari
Email: nadhikari@auaf.edu.af

Course Overview

This course aims to discuss how Web systems are programmed and maintained and how online pages are created and delivered by Web servers and used by clients. This course provides an introduction to web development techniques that use HTML, CSS, and JavaScript as web development essentials including database connectivity and Basics of PHP. Topics to be covered include Web systems and technologies, information architecture, Web development, client-side programming, server-side programming, Web services, and servers JavaScript, Database, and PHP.

Learning Objectives

  • Understand the fundamentals of HTML.
  • Apply CSS to create professional web pages.
  • Build responsive websites for different devices.
  • Understand basic web accessibility principles.
  • Use GitHub to manage web development projects.

Course Policies

Attendance

This course follows University policies regarding attendance, prayer times, and academic integrity as contained in the Academic catalog and the Student Handbook. When more than 25% of the course classes have been missed for any reason, whether excused or unexcused, the student will attain an “F” grade for the course

  • No makeup quizzes/test/exams will be given

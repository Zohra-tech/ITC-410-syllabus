SYLLABUS

ITC 410

Web Development

This course introduces students to the principles and practices of web development using HTML, CSS, and modern tools.

Instructor: Nirmal Adhikari
Email: nadhikari@auaf.edu.af

Course Overview

This course provides an introduction to web development and covers the fundamental concepts required to design and develop modern websites.

Learning Objectives

  • Understand the fundamentals of HTML.
  • Apply CSS to create professional web pages.
  • Build responsive websites for different devices.
  • Understand basic web accessibility principles.
  • Use GitHub to manage web development projects.

Course Schedule

Week 1 Introduction to Web Development
Week 2 HTML Fundamentals
Week 3 Semantic HTML
Week 4 CSS Fundamentals
Week 5 CSS Layout and Positioning
Week 6 Flexbox and Grid
Week 7 Responsive Web Design
Week 8 Forms and User Input
